# 🛍️ E-Commerce Website (Frontend)

This is a responsive e-commerce website built using **HTML**, **CSS**, **JavaScript**, and **Bootstrap**. It simulates the frontend of a modern online store with a focus on clean design, user experience, and mobile-first responsiveness.

## 🔧 Tech Stack

- **HTML5** – Structure and semantic layout  
- **CSS3** – Custom styles for a clean and modern look  
- **Bootstrap 5** – Grid system and responsive design  
- **JavaScript (Vanilla)** – Interactivity and DOM manipulation  

## ✨ Features

- **Home Page with Product Grid** – Browse a collection of products displayed in a clean, responsive card layout.
- **Product Detail View** – Click on a product to view more details in a modal or separate section.
- **Search Functionality** – Filter products dynamically by name using JavaScript.
- **Add to Cart System** – Add items to a cart, view total price, and remove products (optionally saved in local storage).
- **Responsive Design** – Mobile-friendly layout using Bootstrap’s grid and utility classes.
- **Reusable Components** – Navigation bar, product cards, and footer for consistent UI across pages.
